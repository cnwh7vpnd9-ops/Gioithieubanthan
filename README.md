# My Little Space — Website giới thiệu bản thân

Website giới thiệu cá nhân dành cho học sinh **lớp 10A6 — Trường THPT Phú Nhuận**, được thiết kế theo phong cách **Vibrant & Colorful**: gradient tím–hồng–cam, điểm nhấn xanh ngọc, thẻ glassmorphism, chuyển động nhẹ và bố cục responsive.

## Xem website

Sau khi bật GitHub Pages, website sẽ được xuất bản tại:

`https://cnwh7vpnd9-ops.github.io/Gioithieubanthan/`

## Cấu trúc

- `index.html` — nội dung và cấu trúc các section.
- `style.css` — bảng màu, hiệu ứng, animation và responsive layout.
- `script.js` — menu mobile, chuyển giao diện sáng/tối, thanh tiến trình cuộn và hiệu ứng xuất hiện.

## Tùy chỉnh nội dung

1. Mở `index.html`.
2. Thay **“Tên của bạn”** bằng tên muốn hiển thị.
3. Chỉnh sửa phần giới thiệu, sở thích, mục tiêu và mốc thời gian theo thông tin thật của bạn.
4. Có thể thay hình minh họa avatar bằng ảnh cá nhân; hãy cân nhắc quyền riêng tư trước khi đăng ảnh hoặc thông tin liên hệ công khai.

> Để hạn chế lộ thông tin cá nhân trên website công khai, trang hiện chỉ hiển thị **năm sinh 2011**, không hiển thị ngày/tháng sinh đầy đủ.

## Chạy thử

Không cần cài đặt package. Mở trực tiếp `index.html` bằng trình duyệt hoặc dùng tiện ích Live Server trong VS Code.

## Bật GitHub Pages

1. Vào **Settings → Pages** trong repository.
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn branch **main**, folder **/(root)** rồi nhấn **Save**.
4. Đợi GitHub Pages hoàn tất triển khai; mở đường dẫn website được hiển thị trong phần Pages.
